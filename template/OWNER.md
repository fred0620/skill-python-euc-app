## 資料

- **處理什麼**：待填（例如：使用者自己加入的報表，可能含客戶名稱與金額）。
- **存在哪裡**：只在使用者的電腦。使用者資料在 `workspace/`，上傳的暫存在工具結束時刪除。
- **輸出給誰**：待填（例如：Excel 先由人核對，再進入後續流程）。工具不會自動送出任何資料。
- **連網時機**：第一次安裝從 GitHub 下載 uv 與 Python；其他時間不連外。

## 出問題時

1. 使用者執行 `run.bat rollback` 退回上一版，回報版本號（畫面左上角）和 `workspace/logs/app.log`。
2. 負責人修正後發布新版，在 CHANGELOG 寫明影響，並通知使用者更新。
3. 如果輸出可能有誤，先通知使用者暫停使用，改回人工作業。

## 停用

通知使用者停止使用，請他們備份 `workspace` 後刪除整個資料夾，再封存程式碼專案。
